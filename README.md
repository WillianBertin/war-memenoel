# 🚀 War Memenoel — Ultra Edition 3D

Jogo *arcade* de nave espacial em HTML5 Canvas com 22 setores, chefões temáticos (Papai Noel Espacial, Deus do Natal e Grinch Cibernético), Modo Infinito e ranking global em tempo real com Firebase.

👉 **[Jogar agora no GitHub Pages](https://willianbertin.github.io/war-memenoel/)**

## ✨ Recursos
- **3 Naves Jogáveis:** Interceptor V-1 (ágil), Destruidor Plasma (blindado) e Artilharia Quantum (mísseis teleguiados), com cor customizável.
- **22 Setores + Modo Infinito:** dificuldade progressiva, mini-chefes, meteoros, clima espacial e batalhas finais com ataques exclusivos.
- **Hangar com Upgrades Permanentes:** acumule créditos a cada partida para melhorar HP, Dash/Bullet Time e Drones.
- **Controles Completos:** Mouse, Toque (mobile com botões táteis), Teclado e Gamepad USB.
- **Ranking Global & Conquistas:** sincronização em tempo real via Firebase Realtime Database com fallback offline.

## 🎮 Controles
| Ação | PC (Teclado/Mouse) | Celular (Toque) | Gamepad |
| :--- | :--- | :--- | :--- |
| **Mover** | Mouse ou `WASD` / Setas | Arrastar na tela | Analógico Esquerdo |
| **Super Laser** | `Espaço` | Botão `SUPER LASER` | Botão `A` / `X` |
| **Bullet Time** | Segurar `Shift` | Segurar `⏳ BT` | Botão `LB` / `L1` |
| **Dash (Esquiva)** | `E` | Botão `⚡ DASH` | Botão `B` / `O` |
| **Pausar** | `P` ou `Esc` | Botão `PAUSAR` | — |

## 🛠️ Tecnologias
- HTML5 Canvas 2D & Web Audio API (trilha e efeitos procedurais)
- CSS3 responsivo + suporte a PWA (tela cheia no celular)
- Firebase Realtime Database
